Real-time Supabase presence & live cursor collaboration

Description & Specifications

Implement multi-tenant presence and collaborative viewport cursor rendering across active mobile project canvases. State updates must be broadcast over Supabase Realtime Channels with coordinate interpolation and client-side heartbeat validation.

javascript lib/realtime/presenceChannel.ts Connected 
const room = supabase.channel('workspace:wm-142', {
  config: { presence: { key: session.user.id } }
});

room
  .on('presence', { event: 'sync' }, () => {
    const newState = room.presenceState();
    dispatch(syncRemoteCursors(newState));
  })
  .subscribe(async (status) => {
    if (status === 'SUBSCRIBED') {
      await room.track({ x, y, user: currentUser.name });
    }
  });

Critical Implementation Constraints

  • Transmission throttle must stay locked at ≤ 25ms to avoid Supabase rate limiting tier quotas.
  • Viewport offset transforms must map accurately between desktop ultra-wide monitors and tablet devices.
  • Graceful disconnection banner when socket drops before attempting retry backoff.
